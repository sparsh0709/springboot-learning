# Spring Boot

## What is Spring Boot?

Spring Boot is a Java framework built on top of the Spring Framework that simplifies backend development.

It reduces configuration and helps developers build production-ready applications quickly.

---

## Why was Spring Boot created?

Before Spring Boot, creating a Spring application required a lot of manual configuration.

Spring Boot provides:
- Auto Configuration
- Embedded Web Server (Tomcat)
- Dependency Management
- Production-ready features

This allows developers to focus on writing business logic instead of configuration.

---

## What can we build using Spring Boot?

- REST APIs
- Web Applications
- Microservices
- Enterprise Applications
